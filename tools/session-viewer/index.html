Claude Code セッションビューア

Claude Code のセッション記録 (.jsonl) を、チャットの形で読みやすく表示する HTML ファイルです。 1ファイルで動き、インストールは要りません。

Claude Code は、やりとりのすべてを %USERPROFILE%\.claude\projects\<プロジェクト>\<セッションID>.jsonl に1行1件の JSON で残しています。 このビューアはそれを読み込み、発言・思考・ツール呼び出しと結果を分けて並べます。

claude-session-viewer.html をダウンロード   試し用の sample-session.jsonl

使い方

  1. ダウンロードした HTML を Chrome か Edge で開きます。
  2. .jsonl をドロップするか、枠をクリックして選びます。
  3. フォルダごと選ぶこともできます。ログのフォルダを開く で %USERPROFILE%\.claude\projects\<プロジェクト> を選ぶと、セッションが新しい順に並びます。セッションの題名、最初の発言、作業フォルダで絞り込めます。

表示

  • 上の欄に、ファイル名、セッション ID、作業フォルダ、モデル、発言とツール呼び出しの回数、期間、トークン数の目安が出ます。
  • 思考、ツール呼び出し、サブエージェント、システムイベントは、ボタンで表示を切り替えられます。
  • ツール呼び出しは種類ごとに見やすく表示します。Bash はコマンド、Edit は変更前と変更後、Read はファイル名です。
  • 本文を検索すると、該当箇所に印が付き、閉じている欄も開きます。

トークン数は、入力 (キャッシュ作成を含む) と出力を足し合わせた目安です。キャッシュの読み込みは数えていないので、請求額とは一致しません。

外に送るもの

ありません。ファイルはブラウザの中で読むだけで、ネットワークには出しません。セッション記録には API キーやファイルの中身が含まれることがあるので、人に画面を見せるときは注意してください。
