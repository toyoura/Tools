Gemini TTS ナレーション生成

テキストファイルから、Gemini の音声合成 API でナレーションの mp3 を作る短い Python スクリプトです。 英語のナレーションを作るために書きました。

tts_generate.py をダウンロード

動く環境

  • Python 3 と pip install google-genai
  • ffmpeg (PATH が通っていること。wav を mp3 にするのに使います)
  • Gemini の API キー (環境変数 GEMINI_API_KEY か GOOGLE_API_KEY)

使い方

読ませたい文をテキストファイルに書き、出力名 (拡張子なし) と一緒に渡します。

python tts_generate.py narration script.txt

いま居るフォルダに narration.wav と narration.mp3 ができます。

中身

  • モデルは gemini-2.5-flash-preview-tts、声は Kore です。声はスクリプト冒頭の VOICE_NAME で変えられます。声の一覧は Google の 音声生成のドキュメント にあります。
  • API が返すのは 24 kHz・モノラル・16 bit の PCM です。これを wav に包み、ffmpeg で mp3 (VBR、品質 2) にします。
  • テキストは1回の呼び出しでまとめて送ります。長い原稿は、段落ごとにファイルを分けたほうが扱いやすくなります。

外に送るもの

テキストファイルの中身が Google の Gemini API に送られます。
