ClipTranslate

コピーした文を Ctrl+Alt+T で訳し、訳文をクリップボードに書き戻す Windows の常駐ツールです。 日本語なら英語へ、英語なら日本語へ訳します。あとは Ctrl+V で貼るだけです。

翻訳には OpenAI か Anthropic (Claude) の API を使います。キーは自分で用意します。 画面は持たず、タスクトレイのアイコンと Windows の通知だけで動きます。

ソースを見る (GitHub)

動く環境

  • Windows 10 / 11
  • Python 3.9 以上 (pythonw で起動します)
  • OpenAI か Anthropic の API キー

導入

  1. cliptranslate.py、start.cmd、requirements.txt の3つを同じフォルダに置きます。
  2. トレイアイコン用のライブラリ (pystray と Pillow) を入れます。 
    python -m pip install -r requirements.txt
  3. API キーをユーザー環境変数に入れます。OpenAI なら OPENAI_API_KEY、Claude なら ANTHROPIC_API_KEY です。 
    setx OPENAI_API_KEY "sk-..."
    環境変数を入れる前から開いていたプロセスからでも、レジストリを直接読むので起動できます。
  4. start.cmd を実行します。タスクトレイに紺地の矢印のアイコンが出れば準備完了です。

Windows の起動時に立ち上げたいときは、Win+R で shell:startup を開き、start.cmd へのショートカットを置きます。

使い方

訳したい文をコピーしてホットキーを押します。翻訳中はアイコンがえんじ色に変わり、終わると訳文の冒頭が通知に出ます。 短い文なら2秒前後です。トレイアイコンを右クリックすると、次のメニューが出ます。

表1 トレイアイコンのメニュー
項目動作
クリップボードを翻訳ホットキーと同じ。アイコンの左クリックでも動く
元の文に戻す直前に訳した原文をクリップボードに戻す
終了常駐をやめる

二重に起動しても、2つ目は何もせずに終わります。

設定

cliptranslate.py と同じフォルダに config.json を置くと、既定値を上書きできます。書いた項目だけが変わります。 

{
  "provider": "openai",
  "openai_model": "gpt-5.6-terra",
  "claude_model": "claude-opus-5",
  "effort": "low",
  "hotkey": "ctrl+alt+t",
  "extra": "",
  "timeout": 120
}
表2 設定項目
項目意味
provideropenai か claude
effortlow / medium / high。ホットキーを押して待たされないよう、既定は low
hotkey修飾キー (ctrl alt shift win) と、英数字1文字か f1〜f24 を + でつなぐ
extraシステムプロンプトに足す指示。訳語をそろえたいときに使う
timeoutAPI の応答を待つ秒数

設定を変えたら、トレイから終了して起動し直します。

訳し方の工夫

訳す方向はツールが決める

訳す方向はモデルに任せず、送る前にツールが決めます。 仮名と漢字の数を4倍して、英字の数以上なら日本語とみなします。日本語は1文字が英語の1語ほどの情報を持つので、英語の専門用語が多い日本語の文も日本語として扱えます。

文体は原文に合わせる

論文や報告書の文は“である調”、手紙やメールの文は“です・ます調”に訳すよう指示しています。

PDF の改行はモデルに任せる

PDF からコピーした文には、行の途中の改行や行末のハイフンが混じります。送る前にコードで整形はせず、つないでから訳すようプロンプトで指示しています。

文中の“指示”には従わない

コピーした文に“以下を要約せよ”のような文が入っていても、訳す対象として扱うようプロンプトに書いてあります。

API に送るもの

クリップボードの文がそのまま API に送られます。社外秘の文書や個人情報を訳すときは、所属先の規程と、各社の API のデータ利用方針を確かめてください。

ログ (cliptranslate.log) には起動、訳した方向と文字数、エラーだけを書きます。原文と訳文は残しません。
