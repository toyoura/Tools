MdReader

Markdown・LaTeX・テキストの原稿を、ブラウザで1文ずつ読み上げるツールです。 読んでいる文に色が付き、気になった箇所はクリック1つで Cursor のその行に飛べます。

音声は Microsoft Edge の読み上げ (edge-tts) を使うので、API キーは要りません。つながらないときは Windows 標準の音声に切り替わります。 Cursor (VS Code) の中で完結させたい人向けに、拡張版も用意しました。

ソースを見る (GitHub)   Cursor 拡張 (mdreader-0.1.0.vsix)   試し読み用の sample.md

動く環境

  • Windows 10 / 11 (ほかの OS でも動きますが、音声の切り替えと起動用の bat は Windows 向けです)
  • Python 3.10 以上と、pip install edge-tts fastapi uvicorn
  • Cursor (cursor コマンドが PATH にあること。なければ code を使います)

起動

src の中身を1つのフォルダに置き、MdReader.bat に Markdown ファイルをドロップします。 1回目はサーバが最小化された状態で立ち上がり、ブラウザが開きます。2回目からのドロップは、開いているタブがそのファイルに切り替わります。 

python server.py path\to\paper.md

引数なしで起動するとファイル選択の画面が出ます。終わるときは、最小化されているコンソールを閉じます。

使い方

本文の文をクリックすると、そこから読み直します。左の目次で節へ飛べます。速度は 0.8〜2.0 倍で、ピッチは変わりません。 Cursor で保存すると自動で読み込み直し、同じ文から続きを読みます。

何を読み、何を飛ばすか

表2 Markdown の扱い
要素扱い
見出し・段落・箇条書き・引用読む (記号は除く)
コードブロック・表・数式ブロック・フロントマター飛ばす (灰色で表示)
リンク、Obsidian の [[note|alias]]表示テキストだけ読む
インライン数式 $x$“数式”と読む

.tex もそのまま開けます。% のコメント行、プリアンブル、figure や table の環境、\ref や \cite は飛ばし、\caption と本文だけを読みます。 文は句点で区切り、150字を超えるときは読点でさらに割ります。どの文も元のファイルの行範囲を持っているので、ハイライトとエディタの行がずれません。

声の選び方

日本語の原稿でも、Abstract や図のキャプションは英語で書くことが多いものです。既定の“自動”では文ごとに日本語の文字を含むかを見て、日本語の声と英語の声を切り替えます。 一覧から特定の声を選べば、常にその声で読みます。

音声合成が止まったとき

edge-tts は Edge の読み上げを使う非公式のクライアントなので、オフラインや仕様変更で止まることがあります。そのときは Windows 標準の SAPI に自動で切り替わり、画面の右上に注意が出ます。 一度失敗すると、120秒は edge-tts を試しません。環境変数 MDREADER_TTS=sapi で、はじめから SAPI に固定できます。

Cursor 拡張

拡張機能の画面で “VSIX からインストール” を選び、mdreader-0.1.0.vsix を指定します。サーバは拡張が自分で起動します (Python と上記のライブラリは必要です)。 拡張版は保存前の編集もそのまま読み、読んでいる文にエディタのカーソルが乗ります。

表3 拡張のキー操作
操作キー
再生 / 一時停止Ctrl+Alt+Space
次の文 / 前の文Ctrl+Alt+] / Ctrl+Alt+[
カーソル位置から読むCtrl+Alt+Enter

外に送るもの

読み上げる文は、音声合成のために Microsoft の読み上げサービスへ送られます。外に出せない原稿は、MDREADER_TTS=sapi で Windows 内だけで読ませてください。
