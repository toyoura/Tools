Lab Tools

大学で研究と授業をしながら、Claude Code と作ってきたツールを置いています。 あなたの Claude Code や OpenAI Codex に読ませれば、あなたの環境で動くものを作ってくれることでしょう。 アイコンを押すと、それぞれの説明ページに移ります。

ツール

  • ClipTranslate クリップボードをホットキーで日英翻訳
  • Reply LLM Thunderbird で返信の下書きを書く
  • MdReader 原稿を1文ずつ読み上げる
  • セッションビューア Claude Code の記録をチャットの形で読む
  • Gemini TTS テキストからナレーションの mp3 を作る
