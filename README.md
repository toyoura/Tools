# Lab Tools

[English](README.en.md) | 日本語

大学で研究と授業をしながら、Claude Code と作ってきたツールを置いています。
あなたの Claude Code や OpenAI Codex に読ませれば、あなたの環境で動くものを作ってくれることでしょう。
アイコンを押すと、それぞれの説明ページに移ります。
