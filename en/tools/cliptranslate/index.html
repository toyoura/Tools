ClipTranslate

Copy some text, press Ctrl+Alt+T, and the clipboard now holds the translation. Japanese goes to English and English goes to Japanese. Paste it with Ctrl+V.

ClipTranslate runs in the Windows system tray. It calls the OpenAI or Anthropic (Claude) API with your own key. There is no window: you see only the tray icon and Windows notifications. The menu and notifications are in Japanese.

View the source (GitHub)

Requirements

  • Windows 10 / 11
  • Python 3.9 or later (started with pythonw)
  • An OpenAI or Anthropic API key

Setup

  1. Put cliptranslate.py, start.cmd and requirements.txt in one folder.
  2. Install the libraries for the tray icon (pystray and Pillow). 
    python -m pip install -r requirements.txt
  3. Set your API key as a user environment variable: OPENAI_API_KEY for OpenAI, ANTHROPIC_API_KEY for Claude. 
    setx OPENAI_API_KEY "sk-..."
    The tool also reads the variable from the registry, so it works even when started from a process that was open before you set it.
  4. Run start.cmd. A navy icon with two arrows appears in the tray.

To start it with Windows, press Win+R, open shell:startup, and put a shortcut to start.cmd there.

Usage

Copy the text and press the hotkey. The icon turns dark red while the request is running, and a notification shows the start of the translation when it is done. A short sentence takes about two seconds. Right-click the tray icon for this menu:

Table 1. Tray menu
ItemWhat it does
Translate clipboard (クリップボードを翻訳)Same as the hotkey. A left click on the icon does this too
Restore original (元の文に戻す)Puts the text you last translated back on the clipboard
Quit (終了)Stops the tool

If you start it twice, the second copy exits without doing anything.

Settings

Put a config.json next to cliptranslate.py to override the defaults. Only the keys you write are changed. 

{
  "provider": "openai",
  "openai_model": "gpt-5.6-terra",
  "claude_model": "claude-opus-5",
  "effort": "low",
  "hotkey": "ctrl+alt+t",
  "extra": "",
  "timeout": 120
}
Table 2. Settings
KeyMeaning
provideropenai or claude
effortlow / medium / high. The default is low so that you are not kept waiting after the hotkey
hotkeyModifiers (ctrl alt shift win) and one letter, digit or f1–f24, joined with +
extraExtra instructions added to the system prompt, for example to fix how certain terms are translated
timeoutSeconds to wait for the API

After changing the settings, quit from the tray and run start.cmd again.

How it translates

The tool picks the direction

The direction is decided before the request, not by the model. If four times the number of kana and kanji is at least the number of Latin letters, the text is treated as Japanese. One Japanese character carries about as much as one English word, so Japanese text full of English technical terms still counts as Japanese.

The register follows the source

Papers and reports are translated into the plain written style of Japanese (de-aru); letters and emails into the polite style (desu/masu).

PDF line breaks are left to the model

Text copied from a PDF has line breaks in the middle of sentences and words split by hyphens. The tool sends it as is and tells the model to join the lines before translating.

Instructions inside the text are not followed

If the copied text contains something like “Summarize the following”, the prompt says to translate it as text, not to obey it.

What is sent to the API

The clipboard text is sent to the API as is. Before translating confidential documents or personal data, check your organization’s rules and the provider’s data usage policy.

The log (cliptranslate.log) records only start-up, the direction and length of each translation, and errors. It never stores the source text or the translation.
