Gemini TTS Narration

A short Python script that turns a text file into a narration mp3 with the Gemini speech generation API. I wrote it to make English narration.

Download tts_generate.py

Requirements

  • Python 3 and pip install google-genai
  • ffmpeg on PATH (to convert wav to mp3)
  • A Gemini API key in GEMINI_API_KEY or GOOGLE_API_KEY

Usage

Write the text in a file and pass it with an output name (without extension).

python tts_generate.py narration script.txt

narration.wav and narration.mp3 are written to the current folder.

How it works

  • The model is gemini-2.5-flash-preview-tts with the voice Kore. Change VOICE_NAME at the top of the script to use another voice; the list is in Google’s speech generation docs.
  • The API returns 24 kHz mono 16-bit PCM. The script wraps it in a wav file and converts it to mp3 (VBR, quality 2) with ffmpeg.
  • The whole text goes in one request. For a long script, one file per paragraph is easier to handle.

What leaves your computer

The contents of the text file are sent to Google’s Gemini API.
