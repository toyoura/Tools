MdReader

Reads your Markdown, LaTeX or text draft aloud in the browser, one sentence at a time. The sentence being read is highlighted, and one click takes Cursor to that line.

Speech comes from Microsoft Edge’s text-to-speech (edge-tts), so no API key is needed. When it is unreachable, the tool falls back to the voices built into Windows. There is also an extension for those who want to stay inside Cursor (VS Code). It was made for Japanese drafts, and the interface is in Japanese; English sentences are read with an English voice.

Requirements

  • Windows 10 / 11 (it runs elsewhere, but the speech fallback and the launcher bat are for Windows)
  • Python 3.10 or later, and pip install edge-tts fastapi uvicorn
  • Cursor (the cursor command on PATH; code is used otherwise)

Starting

Put the contents of src in one folder and drop a Markdown file onto MdReader.bat. The first drop starts the server minimized and opens the browser. Later drops switch the open tab to the new file. 

python server.py path\to\paper.md

Without an argument it opens a file picker. To quit, close the minimized console.

Click a sentence to read from there. The table of contents jumps to sections. Speed is 0.8–2.0× without changing pitch. When you save in Cursor, the page reloads the file and continues from the same sentence.

What is read and what is skipped

Table 2. Markdown handling
ElementHandling
Headings, paragraphs, lists, quotesRead (markup removed)
Code blocks, tables, math blocks, front matterSkipped (shown in grey)
Links and Obsidian [[note|alias]]Only the visible text is read
Inline math $x$Read as “数式” (formula)

.tex files open as they are. Comment lines, the preamble, figure and table environments, \ref and \cite are skipped; \caption and the body text are read. Sentences are split at full stops, and those over 150 characters again at commas. Every sentence keeps its line range in the source file, so the highlight always matches the editor.

Voices

Even a Japanese paper usually has its abstract and figure captions in English. In the default “auto” mode, each sentence is checked for Japanese characters and read with a Japanese or an English voice. Pick a voice from the list to use it for everything.

When speech synthesis stops

edge-tts is an unofficial client for Edge’s read-aloud service and can stop working when offline or when the service changes. The tool then switches to Windows SAPI and shows a notice at the top right. After one failure it waits 120 seconds before trying edge-tts again. Set MDREADER_TTS=sapi to use SAPI from the start.

Cursor extension

In the Extensions view, choose “Install from VSIX” and select mdreader-0.1.0.vsix. The extension starts the server itself (Python and the libraries above are still needed). It reads unsaved edits as they are and moves the editor cursor along with the sentence being read.

What leaves your computer

The sentences are sent to Microsoft’s read-aloud service for synthesis. For drafts that must not leave your machine, set MDREADER_TTS=sapi so that everything stays in Windows.
